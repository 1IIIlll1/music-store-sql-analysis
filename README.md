# Music Store Data Analysis — SQL Portfolio Project

## Project Overview

This project uses SQL to analyse a digital music store's sales data. The aim is to explore customer purchasing behaviour, revenue performance, music genre popularity and employee sales performance.

The analysis was completed using PostgreSQL and the Chinook database.

## Database

The project uses the following tables:

- Customer
- Invoice
- InvoiceLine
- Track
- Album
- Artist
- Genre
- Employee

## Business Questions

The analysis explores 10 questions:

1. Customer invoice transactions
2. Total spending per customer
3. Revenue generated by music genre
4. Invoice value categorisation
5. Invoices above average value
6. Identification of high-spending customers
7. Customer spending rankings
8. Monthly revenue trends
9. Revenue generated by employees
10. Top 10 tracks by revenue

## SQL Skills Demonstrated

- JOINs
- GROUP BY and aggregate functions
- CASE statements
- Subqueries
- Common Table Expressions (CTEs)
- Window functions
- Date-based analysis
- Sorting and filtering

## Tools Used

- PostgreSQL

- GitHub
